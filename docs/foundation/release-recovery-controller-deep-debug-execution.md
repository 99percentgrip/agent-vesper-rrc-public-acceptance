# Controlled public RRC validation

This repository is an isolated copy of Agent Vesper for controlled RRC workflow,
process, repair and publication acceptance. Test releases are validation artifacts.
Use https://github.com/99percentgrip/agent-vesper for supported installations.

The runtime source matches the locally verified RRC/OpenAI authentication repair.
Local evidence: complete `cargo xtask verify`, 64 exact acceptance cases,
77 dedicated RRC cases on stable/MSRV and 12 authentication UI cases passed.
Current native/prerequisite/producing workflow evidence is still pending.

copy does not publish those private diagnostic archives or financial annotations.
